# AuthSync

**Re-login once, refresh everywhere.**

When a Jira, Confluence, or internal-tool session expires, you log in again and then reload every other stale tab by hand. AuthSync watches the hostnames you choose. After you sign in, or reload, in one tab, it reloads the other matching tabs in the background.

## Install

Install AuthSync from the Mac App Store. The store button on the guide is not active yet.

The guide is the [wiki](https://github.com/drecrumbs/AuthSync/wiki). It also covers a manual install for Safari, Chrome, and Firefox.

## Privacy

AuthSync does not read page content, cookies, or passwords, and it does not send your browsing anywhere. The [privacy policy](https://drecrumbs.github.io/AuthSync/legal/privacy-policy.html) describes what stays on your Mac.
